Job Copilot

Job Copilot is a personal job-search assistant used by a small, invited group of people. It helps them find vacancies, write CVs and cover letters, and keep track of the applications they send.

Gmail connection

A user can choose to connect a Gmail account, usually one created only for job applications. Job Copilot then reads, with read-only access, the replies employers send to those applications, so it can show which applications got an answer, an invitation or a rejection. It never sends, changes or deletes email.

Read the privacy policy for exactly what is read, kept and shared.
